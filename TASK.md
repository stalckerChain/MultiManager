# TASK — Внешние пути профилей браузера из stAuto0

## Текущая задача

Импортировать аккаунты из внешнего проекта `C:\Users\stalcker\AI\stAuto0` в MultiManager без копирования браузерных профилей. Профили должны оставаться в `stAuto0\config\chrome_accounts\<profile_directory>`, а MM должен хранить абсолютный путь в БД и использовать его при запуске браузера.

MM работает в гибридном режиме:

- `profile_path` задан — используется внешний user-data-dir;
- `profile_path` равен `NULL` — используется стандартный путь MM.

MM не перемещает и не копирует файлы внешнего профиля автоматически. Очистка кэша, cookie-инжект и другие операции, изменяющие внешний профиль, выполняются только при явном вызове соответствующей операции.

## Новая причина после проверки packaged-логов и БД

Проблема с токеном не является причиной текущего нестарта: в свежем логе packaged-сборки токен отмечен как `SET`, а stAuto0 успешно выполняет запрос к `/api/internal/profiles`.

- **Лог GUI:** `C:\Users\stalcker\AppData\Roaming\multimanager-gui\logs\app-2026-08-04.log`.
- **Лог run:** `C:\Users\stalcker\AppData\Local\Programs\multimanager-gui\resources\logs\runs\cc2b03b3-59f0-4aa1-b412-934bdeb167fa\auto_002.log`.
- Лог содержит `Found 0 account(s) to run (mm_mode=True)` и `All accounts processed`: Python завершился штатно, не доходя до запуска браузера.
- В текущей БД `C:\Users\stalcker\AppData\Roaming\CloakManager\app.db` профиль имеет `name = auto_002`, `number = 1`, `profile_path = NULL`.
- В `src/executor/index.js` диапазон строится из `profile.number`: для этого профиля получается `--range=001-001`.
- stAuto0 сопоставляет диапазон с именами `auto_001`, поэтому профиль `auto_002` не находится и возвращается ноль аккаунтов.
- В более раннем packaged-логе с двумя профилями зафиксирована та же инверсия: `profileName=auto_002` запускается с `range=001-001`, а `profileName=auto_001` — с `range=002-002`.
- Это объясняет различие: ручной запуск браузера использует UUID профиля напрямую, а automation использует ошибочный диапазон по порядковому `number`.

**Точечное исправление:** формировать диапазон из числового суффикса `profile.name` (`auto_002` -> `002-002`) либо передавать stAuto0 точное имя аккаунта, не используя DB-порядок `number`. Не исправлять данные БД вручную как workaround: `number` является порядком записи и не обязан совпадать с номером аккаунта. ✅

**Результат:** `executor/index.js:94-98` — парсинг `accountNumber` из `profileName.match(/\d+$/)`. `npm test` — 52 файла, 804 теста ✅. Сборка портабл + инсталлер ✅. Гейт №3 пройден.
