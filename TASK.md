# TASK — Save не должен пересинхронизировать проекты

## Описание

При сохранении настроек автоматизации (`PUT /api/settings/automation`) бэкенд автоматически синхронизирует проекты из файловой системы. Из-за этого удалённые пользователем проекты возвращаются после нажатия Save.

## План реализации

1. **`src/api/settings.js`** — удалить блок авто-синхронизации проектов (строки ~148–200):
   - Убрать чтение `projectsDir`
   - Убрать вызов `projectQueries.sync(files)`
   - Убрать `matrix.batchUpdate(entries)`
   - `syncResult` остаётся `{ added: 0, removed: 0, total: 0 }` (инициализация в строке 149)

2. **Проверка:** `npm test`

3. **Документация:** не требуется (поведение приводится к ожидаемому)
