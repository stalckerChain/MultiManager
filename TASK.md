# TASK — Shift-выбор ячеек в матрице синхронизации

## Цель

В разделе Automation → Matrix добавить возможность включать диапазон чекбоксов
через Shift-click. Обычный клик должен сохранить текущее поведение переключения
одной ячейки.

## Согласованное поведение

1. Обычный клик переключает одну доступную ячейку и запоминает её как последнюю
   выбранную.
2. После обычного клика по ячейке Shift-click по другой доступной ячейке включает
   прямоугольный диапазон между ними: от минимального до максимального индекса
   строки профиля и от минимального до максимального индекса столбца проекта.
3. В диапазон входят обе ячейки, по которым выполнены клики.
4. Shift-операция копирует состояние anchor (включённое или выключённое) на весь
   диапазон.
5. Недоступные ячейки, отключённые через `allowed_profile_ids`, не изменяются.
6. Диапазон рассчитывается по текущему отображению матрицы: активным проектам и
   строкам `filteredProfiles` с учётом поиска.
7. Shift-click без ранее выбранной ячейки работает как обычный клик.
8. Изменения остаются локальными в `selectedCells` и сохраняются на сервере
   существующим вызовом `updateMatrix` при создании run. API и схема БД не
   меняются.

## Реализация

Изменить `gui/src/renderer/views/AutomationMatrix.vue`:

- добавить локальное состояние ключа последней кликнутой ячейки;
- обернуть `a-checkbox` в элемент, например `<span>`, с обработчиком
  `@click="handleCellClick($event, record.id, column.projectName)"`;
- убрать `@change="toggleCell(...)"` с `a-checkbox`, чтобы изменение состояния
  выполнялось только новым обработчиком и не происходило двойного переключения;
- в `handleCellClick` проверять `event.shiftKey`: без Shift переключать одну
  ячейку через существующую логику, а с Shift распространять состояние anchor на
  диапазон;
- сохранить существующее одиночное переключение для обычного клика;
- для Shift-click найти индексы профилей в `filteredProfiles` и проектов среди
  активных столбцов, построить прямоугольный диапазон и записать состояние
  anchor в `selectedCells` только для разрешённых ячеек;
- перед построением Shift-диапазона валидировать anchor по текущему
  `filteredProfiles` и активным проектам; если anchor отсутствует среди текущих
  видимых строк/столбцов, обработать клик как обычный и установить новую anchor;
- не менять `isChecked`, `selectedCount`, `getEnabledEntries` и контракт
  `store.updateMatrix`, кроме необходимого подключения нового обработчика;
- корректно обрабатывать отсутствие anchor, изменение поиска, фильтрацию
  профилей и клики по отключённым ячейкам без исключений.

## Тесты

Изменить `tests/unit/gui-matrix-selection.test.js`:

- добавить тесты для вычисления прямоугольного диапазона по строкам и столбцам;
- проверить копирование состояния anchor на все доступные ячейки диапазона,
  включая границы (как включение, так и выключение);
- проверить, что ячейки вне `allowed_profile_ids` не изменяются;
- проверить поведение Shift без anchor как одиночного клика;
- проверить, что обычный клик по-прежнему переключает только одну ячейку;
- проверить диапазон при обратном направлении выбора (от нижней/правой ячейки
  к верхней/левой);
- проверить Shift-click после изменения поиска, когда предыдущий anchor указывает
  на отфильтрованный профиль: диапазон не должен использовать скрытую строку,
  текущая ячейка должна обработаться как новая anchor;
- сохранить существующие проверки `selectedCount` и `getEnabledEntries`.

Тесты должны проверять чистую логику диапазона в стиле существующего файла,
без добавления новой зависимости или изменения API/БД.

Обязательная ручная проверка в GUI:

1. Открыть Automation → Matrix и выполнить обычный клик по доступной ячейке.
2. Выполнить Shift-click по ячейке ниже/правее и убедиться, что весь

3. Проверить обратное направление диапазона.
4. Проверить диапазон при активном поиске профилей.
5. Проверить, что недоступные ячейки не включаются.
6. Создать run и убедиться, что выбранные ячейки переданы существующему
   механизму сохранения матрицы.

## Критерии приёмки

- Shift-click включает прямоугольный диапазон между последней и текущей
  ячейками.
- Обычный клик продолжает переключать одну ячейку.
- Недоступные профили не изменяются.
- Фильтрация профилей не вызывает ошибок и учитывается при расчёте диапазона.
- Существующие серверное сохранение, счётчик выбранных ячеек и создание run не
  регрессируют.
- Целевые тесты, `npm test` и lint проходят.

## Риски и ограничения

- Ant Design Vue передаёт событие изменения отдельно от нативного клика;
  обработчик на обёртке должен читать `shiftKey` из события клика; `@change` на
  `a-checkbox` нужно убрать, чтобы не допустить двойного переключения ячейки.
- Состояние диапазона локальное и не должно отправлять отдельные запросы при
  каждом клике.
- При изменении поиска anchor может ссылаться на скрытую строку; проверка
  anchor в момент Shift-click должна считать такой anchor недействительным и
  использовать текущую ячейку как новую anchor.
- API, безопасность и БД не затрагиваются.
