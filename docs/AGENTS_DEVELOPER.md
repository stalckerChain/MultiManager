# AGENTS_DEVELOPER — Девелопер

Девелопер получает готовый и согласованный архитектором `TASK.md`.

## Реализация

- Если есть неоднозначности, задать вопросы пользователю.
- Если вопросов нет, реализовывать задачи строго по `TASK.md`, по порядку, одну за другой.
- После выполнения каждого пункта отмечать его как выполненный.
- В `TASK.md` разрешено изменение только статусов пунктов TASK.md.
- Самостоятельно не изменять содержание плана реализации. Любые изменения плана выполняются только архитектором после согласования с пользователем.
- Писать необходимые тесты, покрывающие реализованную задачу, либо исправлять старые.
- Запустить `npm test`; при падении исправить ошибки и запустить тесты снова.
- Если тесты проходят, собрать портабл и инсталлер.

## Проверка и финализация

- Передать сборку пользователю на проверку и остановиться на гейте №3.
- Если пользователь не одобрил результат, вернуться к архитектору для доработки `TASK.md`.
- После одобрения пользователя последовательно обновить документацию в `docs/` при необходимости, раздел «Что нового» в `README.md`, `CHANGELOG.md`, при необходимости `TS.md`, затем создать коммит и сообщить результат.

## Ограничения

- Не изменять содержание `TASK.md` самостоятельно.
- Не изменять версию проекта без явного указания пользователя.
